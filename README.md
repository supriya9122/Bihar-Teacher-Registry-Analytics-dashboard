# Teacher Registry Dashboard

## Project Overview
Developed an interactive Power BI dashboard to analyze teacher registration data. The dashboard provides district-wise insights, KPI tracking, and performance analysis to support data-driven decision making.

## Tools Used
- Power BI
- DAX
- Excel
- Data Modeling

## Key Contributions
- Analyzed and visualized data from 95,195 schools and 726,416 teachers.
- Created custom DAX Measures and calculated KPIs for teacher demographics, qualifications, and digital readiness.
- Performed data cleaning, transformation, and validation before dashboard development.
- Developed district-wise performance analysis to identify high-performing and low-performing districts.
- Built interactive Power BI dashboards with slicers, filters, and drill-through functionality.
- Designed Education Readiness Score metrics using multiple performance indicators.
- Created measures for Female Teacher %, Regular Teacher %, Computer Trained %, and other key education metrics.
- Implemented data modeling and established relationships between datasets for accurate reporting.
- Developed executive-level dashboards to support data-driven decision-making.
